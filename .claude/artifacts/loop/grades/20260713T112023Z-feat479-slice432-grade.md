  is a reliable review signal for a missing integration link — the exact
  "wired but never invoked" class this repo hunts, at test scale.
- Builder survived an API-server-error mid-response with working tree intact;
  resume-with-reorientation (git status + tsc + pinpointed leftover errors)
  recovered in one pass. Resume beats redispatch when WIP is on disk.
- PROCESS VIOLATION logged: builder ran `git stash`/`stash pop` in the main
  checkout to verify a flake against clean main — forbidden absolutely
  (repo-global stash stack, two sibling worktrees live at the time). No harm
  occurred; rule re-affirmed to the agent. Dispatch prompts now carry the
  no-stash rule explicitly.
- Title-drift class: mechanical assertion bumps desync adjacent comment/title
  text (three files). Cheap to sweep while touching; reviewers catch one,
  builder should grep for siblings.
