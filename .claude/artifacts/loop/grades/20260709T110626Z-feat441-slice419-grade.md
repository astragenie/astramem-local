## Lessons

- **A fix pass must honor the slice's stated Out-of-scope even when an AC tempts expansion.** The AC-4 "digest surfaces gatedOutCount" gap led the fix agent to build a new `durability_gate_log` table + migration 022 + `SCHEMA_VERSION` 21→22 — explicitly ruled out by the slice Out-of-scope, AC-7 ("log line, not a side table"), and PM triage ("re-score before a table"). It also caused 3 collateral wire-schema test failures. Caught at the human checkpoint and reverted.
- **Uncommitted intermediate builder state is unrecoverable.** The first builder's log-line AC-7 retention was overwritten by the fix agent and had to be re-implemented from the review description. On `autonomous_safe: false` slices, commit the green builder state before a fix pass so a bad fix can be `git checkout`-reverted instead of hand-rebuilt.
- **The PM's `autonomous_safe: false` call was correct.** The HIGH classifier false-positive (rationale-bearing durable atoms misclassified as junk) was exactly the irrecoverable-omission hazard the PM flagged; the human checkpoint also caught the table overreach. An unattended run would have shipped both.
- **`RATIONALE_MARKER_RE` is a bare keyword-presence check → gameable.** Junk with an incidental `since`/`because`/`--` now slips the gate (false-negative). Safe direction per PM's under-gate>over-gate bias and inert at default-`off`, but a real gap before any default-on.

## Decisions

### DEC-419-1: Rejected-candidate retention is a redacted log line, not a table (this slice)

**Rationale**: A dedicated table + migration + SCHEMA_VERSION bump pushes technical_risk into the schema-change band (PM: re-score first) and expands the prod daemon's schema surface for an observability nicety. Log-line through the existing `redactIfEnabled` path + `ingest.log` rotation satisfies AC-7 with zero schema change.

**Consequences**:
- + Slice stays in its scored risk band; no migration on a prod-bound daemon; suite green.
- − Gate activity is not queryable via an API/digest; AC-4's digest half deferred to a fast-follow.

### DEC-419-2: Gate defaults to `off` (opt-in until eval'd)

**Rationale**: Day-one behavior must be byte-identical (AC-2); a `lenient`/`strict` default would silently change persistence on a config read that has no hot-reload.

**Consequences**:
- + Zero-risk rollout; can be revert-flagged.
- − Feature is inert until deliberately enabled; the classifier's residual false-negative surface is untested against real default-on traffic.

### DEC-419-3: Classifier fails OPEN on error

**Rationale**: A durability gate that throws must never poison a distill job or silently drop an atom; on classifier/redaction error the atom is persisted + a warning logged.

**Consequences**:
- + No new crash path; errs toward keeping data (no irrecoverable omission on error).
- − An erroring classifier degrades silently to no-gate; relies on the warn log for detection.

## Surprises

- Fix agent scope-creep: reached for a schema-backed table to close an observability AC despite explicit written scope forbidding it.
- Pre-existing `tests/scripts/post-merge-rebuild.test.ts` Windows-bun `SyntaxError` (Lane B, FEAT-440) surfaced during this slice — unrelated, CI-green, left untouched.

## Followups

- **FF-1 (blocks default-on): tighten `RATIONALE_MARKER_RE`** to require causal/proximity to the trigger clause rather than bare keyword presence anywhere in the atom, before `distill.durabilityGate` is ever defaulted to `lenient`/`strict` in any environment.
- **FF-2: AC-4 digest-surfacing** of `gatedOutCount` (deferred this slice) — surface via `buildSessionDigest` without a new table (e.g. count from the existing job record / structured log source).
- **FF-3 (separate):** fix the pre-existing `post-merge-rebuild.test.ts` Windows-bun SyntaxError.

## What went well

Single-choke-point classifier module (AC-6), closed-union `gatedReason`, ReDoS-safe patterns, fail-open safety, default-off, doctor visibility, redaction-passthrough retention. Both-direction classifier tests + ADR-005 eval floors + junk-pollution fixture give real confidence. The review gate earned its keep: caught a HIGH false-positive and a scope breach that an unattended run would have shipped.

## What went wrong

The fix pass overreached into a schema-backed table, breaching written scope and reddening 3 tests; recovery cost a full extra revert cycle because the good builder state was never committed. Two agents also left stray junk files / dangling refs mid-run.

## What I would do differently next time

Commit the green builder state before dispatching a fix pass on an `autonomous_safe: false` slice. State the "do NOT touch schema / do NOT create tables" constraint in the fix dispatch up front (it was only added on the corrective pass). Scope AC-4's digest requirement more precisely at slice-start so the persistence-source question is decided before build, not discovered mid-fix.
